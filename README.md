# Шпаргалка по комбинаторике

![CI](https://github.com/degor1997-rgb/combinatorics-cheatsheet/actions/workflows/ci.yml/badge.svg)

Небольшой сервис на FastAPI для студентов, которые путаются в формулах комбинаторики.
Отвечаете на два вопроса (важен ли порядок и могут ли элементы повторяться) и получаете
нужную формулу с примером. Здесь же можно посчитать факториал, размещения и сочетания.
В ответе есть и результат, и ход решения, например `C(5,2) = 5! / (2! · 3!) = 10`.

## Маршруты

- `/factorial/{n}`: факториал
- `/permutations?n=5&k=2`: размещения, с `&repeat=true` с повторениями
- `/combinations?n=5&k=2`: сочетания, с `&repeat=true` с повторениями
- `/choose?order=true&repeat=false`: какую формулу выбрать
- `/cheatsheet`: все формулы с примерами
- `/`, `/health`, `/version`: список возможностей и служебные проверки

Если ввести отрицательное число, k больше n (без повторений) или число больше `MAX_N`,
сервис вернёт ошибку 400 и напишет причину.

## Установка

Нужен Python 3.12 или новее.

```bash
git clone https://github.com/degor1997-rgb/combinatorics-cheatsheet.git
cd combinatorics-cheatsheet
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
```

На Windows: `python -m venv .venv`, затем `.venv\Scripts\activate` и `copy .env.example .env`.

В `requirements.txt` то, что нужно для работы сервиса, в `requirements-dev.txt` то же
плюс pytest и httpx2 для тестов.

## Запуск

```bash
python -m uvicorn app_final:app --host 127.0.0.1 --port 8000
```

Документация, где можно отправлять запросы прямо из браузера: http://127.0.0.1:8000/docs

Во время разработки удобно добавить `--reload`: сервер сам перезапустится после
сохранения кода.

## Проверка

```bash
curl http://127.0.0.1:8000/health     # {"status":"ok"}
curl http://127.0.0.1:8000/version    # {"version":"0.1.0"}
```

## Настройки

Задаются в `.env` (шаблон лежит в `.env.example`) или через переменные окружения.
После изменения перезапустите сервер. Сам `.env` в Git не попадает.

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `APP_VERSION` | `0.1.0` | версию в `/version` |
| `MAX_N` | `1000` | максимальные n и k |
| `LOG_LEVEL` | `INFO` | подробность логов: `DEBUG`, `INFO`, `WARNING`, `ERROR` |

## Логи

Пишутся в терминал, где запущен сервер: запуск приложения, каждый расчёт и ошибки ввода.

```

2026-10-15 14:21:11,313 INFO Calculated: 5! = 1 · 2 · ... · 5 = 120
```

Чтобы сохранить логи в файл, добавьте к команде запуска `2>&1 | tee app.log`.

## Тесты

```bash
python -m pytest -v
```

Тесты проверяют расчёты, шпаргалку, `/health`, `/version` и ошибки ввода. Сервер для них
запускать не нужно. Те же тесты запускает GitHub Actions при каждом push и pull request.
Если они прошли, собирается artifact с файлами приложения: вкладка Actions, последний
запуск, раздел Artifacts.

## Диагностика

- `command not found: python` или `No module named ...`: не активировано окружение,
  выполните `source .venv/bin/activate`.
- `Address already in use`: порт занят старым сервером. Найдите его через `lsof -i :8000`
  и остановите командой `kill <PID>` или запустите на другом порту (`--port 8001`).
- `curl: (7) Couldn't connect to server`: сервер не запущен или указан другой порт.
- `zsh: no matches found`: адрес с `?` нужно взять в кавычки.
- Поменяли `.env`, а ничего не изменилось: перезапустите сервер.
- `ValueError` при запуске: в `.env` неверное значение `MAX_N` (нужно число) или `LOG_LEVEL`.
- Код 422: параметр не передан или это не число. Код 400: число недопустимое, причина
  написана в ответе.
- В `/docs` вместо большого числа видно `1.55e+25` или `null`: так браузер показывает очень
  большие числа. Точное значение есть в поле `explanation`.
- `MAX_N` больше 1000 лучше не ставить: на очень больших числах сервис отвечает ошибкой 500.
